# Дольки

**Дольки** — концепция сервиса для коллективных сборов на подарок, где каждый участник вносит равную долю, а сумма сбора прозрачна и подтверждена чеком.

Учебный пет-проект по бизнес-анализу.

## Какую проблему решает

| Проблема | Как решают «Дольки» |
| --- | --- |
| Непрозрачная сумма: неясно, из чего она складывается и сколько стоил подарок | Каждая позиция добавляется со ссылкой на товар или услугу, сумма сбора равна сумме позиций, после покупки организатор прикладывает чек |
| Неравный вклад: одни переводят больше, другие меньше | Сумма делится поровну, взнос сверх дольки возможен только с разрешения организатора |
| Нагрузка на организатора: напоминания, учёт вручную, доплаты из своих | Сервис сам считает дольки и показывает прогресс сбора, взносы копятся на отдельном накопительном счёте |

## Что внутри

```
dolki/
├── index.html                ← лендинг: описание сервиса
├── app.html                  ← веб-приложение: создание сбора, регистрация, приглашения, профиль
├── config.js                 ← ключи подключения к Supabase (общие для всех страниц)
├── supabase/
│   ├── schema.sql            ← вся база с нуля: таблицы, правила доступа, функции, хранилище чеков
│   └── receipts.sql          ← только чеки — для базы, где schema.sql уже запущен
├── fonts/
│   └── Chicoree-OFL.txt      ← лицензия шрифта Chicoree
└── README.md
```

Сайт сделан на чистых **HTML, CSS и JavaScript**: без фреймворков, сборщиков, серверов и Docker. Стили и скрипты лежат внутри самих HTML-файлов, шрифт заголовков встроен в них же. Отдельно вынесен только `config.js` с настройками базы данных.
`, переименуйте его обратно в `app.html`.
- `index.html`, `app.html` и `config.js` должны лежать **рядом, в одной папке**.

> Для заголовков интернет не нужен: шрифт встроен в файлы. Без интернета основной текст покажется системным шрифтом вместо Manrope, на работу сайта это не влияет.
